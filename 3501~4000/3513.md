# 3513. Number of Unique XOR Triplets I
## Description
You are given an integer array `nums` of length `n`, where `nums` is a **permutation** of the numbers in the range `[1, n]`.

A **XOR triplet** is defined as the XOR of three elements `nums[i] XOR nums[j] XOR nums[k]` where `i <= j <= k`.

Return the number of **unique** XOR triplet values from all possible triplets `(i, j, k)`.
## Approach
For $n\le 2$ it's trivial. So we consider the case when $n\le 3$.

First let $2^k\le n<2^{k+1}$
$0=1\oplus 2\oplus 3$, so we can construct $0$.
For $x\in [1,n]$, $x=1\oplus 1\oplus x$,  sincd all of the three are within $[1,n]$, so we can construct all numbers within $[1,n]$.

For $x\in [n, 2^{k+1}-1]$. 
Let $y=x\oplus 2^{k}$. Since the k-th bit of $x$ must be 1, we have:
$$y=x-2^k\le 2^k-1\le n$$
So, y is also in the array, we could choose $a,b$ such that $y=a\oplus b$ and $y\oplus 2^k=x$. Consider the following two cases:
+ $y=1$: $a=2,b=3,2\oplus3=1$
+ $y\ne 1$: $a=1, b=1\oplus y$. Since $y\oplus 1\le y+1\le n$. Both $a$ and $b$ are within the original array.
Therefore for $n\ge 3$, we could construct all the numbers within the range $[0,2^{k+1}-1]$.
## Code
```cpp
class Solution {
    public: int uniqueXorTriplets(vector < int > & nums) {
        int n = nums.size();
        if (n <= 2) return n;
        int res = 1;
        while (res <= n) res <<= 1;
        return res;
    }
};
```
