# 3536. Maximum Product of Two Digits
## Approach
Brute force
## Code (cpp)
```cpp
class Solution {
    public: int maxProduct(int n) {
        int m = -1, sm = -1;
        while (n) {
            int digit = n % 10;
            if (digit >= m) {
                sm = m;
                m = digit;
            } else if (digit >= sm) {
                sm = digit;
            }
            n /= 10;
        }
        return m * sm;
    }
};
```
