# 3702. Longest Subsequence With Non-Zero Bitwise XOR
#algorithm #bitwise_operation
[Problem Link](https://leetcode.com/problems/longest-subsequence-with-non-zero-bitwise-xor/)
## Approach
考慮兩種情況，一種是所有元素都是零，這種情況不管拿幾個元素的結果都是零，因此應該回傳零。

另外一種情況是非全元素為零。假設整個陣列的xor值不為零，那挺好的，直接回傳 `nums.size()`;如果為零呢？我們可以可以隨便拿掉一個不為 0 的元素，假設它的值是 a 好了，那拿掉這元素的 xor 結果就不會是零了，因為 0^a=a，而且a不是0。
## Code
```cpp
class Solution {
    public: int longestSubsequence(vector < int > & nums) {
        bool allZero = true;
        int curr = 0;
        int n = nums.size();
        for (int num: nums) {
            if (num) allZero = false;
            curr ^= num;
        }
        if (allZero) return 0;
        if (curr) return n;
        else return n - 1;
    }
};
```
