# 3517. Smallest Palindromic Rearrangement I
## 題敘
You are given a **palindromic** string `s`.

Return the **lexicographically smallest** palindromic permutation of `s`.
## 方法
把本來的回文從中間切開，把左邊一半依照字母順序去排，這邊我是使用 counting sort。不過需要留意中間的字母，也就是出現次數為奇數的那個，如果本來的回文長度是奇數，需要在(排好的)左邊一半額外拼上那個字母，再拼上(排好的)右邊一半。
## 複雜度
+ 時間 $O(n)$, `n = s.length()`
+ 空間 $O(1)$
## 程式碼
```cpp
class Solution {
    public: string smallestPalindrome(string s) {
        if (s.size() <= 3) return s;

        vector < int > cnt(26);
        char odd = ' ';
        for (char c: s) cnt[c - 'a']++;
        string s1;
        for (int i = 0; i < 26; i++) {
            if (cnt[i] & 1) odd = 'a' + i;
            s1 += string(cnt[i] / 2, 'a' + i);
        }

        string s2 = s1;
        reverse(s2.begin(), s2.end());
        if (odd != ' ') s1.push_back(odd);
        s1 += s2;
        return s1;
    }
};
```
