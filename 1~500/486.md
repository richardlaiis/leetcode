# 486. Predict the Winner
## Approach
DFS，這裡定義的 `dfs` 會 return **當前 player** 在 $[l,r]$ 的區間與另外一個 player 獲得分數的**差** (assume that each player plays optimally)

非常神奇，這方法甚至是網路上抄來的 qwq
## Code (cpp)
```cpp
class Solution {
    public: int dfs(int l, int r, vector < int > & nums) {
        if (l > r) return 0;
        int pick_left = nums[l] - dfs(l + 1, r, nums);
        int pick_right = nums[r] - dfs(l, r - 1, nums);
        return max(pick_left, pick_right);
    }
    bool predictTheWinner(vector < int > & nums) {
        return dfs(0, nums.size() - 1, nums) >= 0;
    }
};
```
