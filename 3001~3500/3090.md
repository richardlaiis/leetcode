# 3090. Maximum Length Substring with Two Cccurrences
#sliding_window #algorithm
## Approach
Sliding window 的經典題，也可以用暴力因為這題數字很小。
## Code
```cpp
class Solution {
    public: int maximumLengthSubstring(string s) {
        int cnt[26] = {
            0
        };
        int left = 0, right = 0, res = 0;
        int n = s.size();
        while (right < n) {
            cnt[s[right++] - 'a']++;
            while (cnt[s[right - 1] - 'a'] > 2) cnt[s[left++] - 'a']--;
            res = max(res, right - left);
        }
        return res;
    }
};
```
