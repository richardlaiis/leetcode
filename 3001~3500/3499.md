# 3499. Maximize Active Section With Trade I
## Approach
1.  Augment the string s.
2. 把字串切成皆為0或皆為1的片段，存進一個陣列 (順序不能打亂)
3. 一個交易成立，若且唯若存在一個皆為 1 的片段，且左右鄰居皆為"皆為0"的片段。交易完成後字串 s 多出的 1 的數量 delta 即為前述左右鄰居的長度之和
4. 遍歷 2. 建立的陣列，找出最大的 delta
5. 所求即為 s 目前 1的數量加上delta扣掉2 (因為原本的 s 經過 augmentation)
## Code

```python
class Solution:
    def maxActiveSectionsAfterTrade(self, s: str) -> int:
        s = "1" + s + "1"
        segs = []
        i, n = 0, len(s)
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            segs.append((s[i], j - i))
            i = j

        m = len(segs)
        delta = 0
        for i in range(m):
            if i == 0 or i == m - 1:
                continue
            if segs[i][0] == "1" and segs[i - 1][0] == "0" and segs[i + 1][0] == "0":
                delta = max(delta, segs[i - 1][1] + segs[i + 1][1])
        return s.count("1") + delta - 2

```
